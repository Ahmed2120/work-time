🔒 تأمين وقواعد Firebase Realtime Database

لتمكين لوحة التحكم من قراءة البيانات بعد تسجيل دخولك كـ Admin، مع منع الزوار غير المصرح لهم، انسخ القواعد التالية وضعها في تبويب Rules داخل Firebase Console: 

{
  "rules": {
    "devices": {
      ".read": "auth != null",
      "$uuid": {
        ".write": true
      }
    },
    "feedbacks": {
      ".read": "auth != null",
      ".write": true
    },
    "users": {
      ".read": "auth != null",
      "$user": {
        ".read": true,
        ".write": true
      }
    }
  }
}

🚀 خطوات تفعيل GitHub Pages مجاناً

  1. ارفع التعديلات إلى GitHub: git push origin main
  2. ادخل إلى صفحة المشروع في GitHub ثم اضغط على Settings ➔ Pages.
  3. في قسم Build and deployment:
    • اختر Source: Deploy from a branch
    • اختر Branch: main و المجلد: /docs
  4. اضغط Save. خلال دقيقة سيظهر لك رابط الموقع المباشر:
    https://your-username.github.io/work_time/
  5. افتح الرابط من هاتفك أو جهازك في أي وقت لمتابعة نشاط التطبيق لايف! 🎯
